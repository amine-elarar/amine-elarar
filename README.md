### 01 — EasyColoc
![EasyColoc](./assets/easycoloc-preview.png)  
Application web de gestion de dépenses entre colocataires.  
- Calcul automatique des soldes et remboursements  
- Stack : **C** (core) · **Laravel** · **PHP** · **MySQL**  
- Fonctionnalités : authentification, tableaux de bord, historiques  

### 02 — Gestion de projets Scrum
![Scrum Manager](./assets/scrum-preview.png)  
Plateforme de suivi de projets en équipe.  
- Attribution des tâches, burndown charts, sprints  
- Stack : **PHP** · **MySQL** · **HTML/CSS** · **JavaScript**  
- Méthodologie : Scrum, backlog priorisé

![WorkSphere](./assets/worksphere-preview.png)  
Organisateur interactif d'espaces de travail en temps réel.  
- Drag & drop d'employés sur plan d'étage  
- Gestion des rôles, zones, déplacements  
- Stack : **JavaScript** (canvas/SVG) · **CSS Grid** · **Responsive**
